# Reaching for the Stars

An interactive data visualization exploring the costs, benefits, and trade-offs of global space exploration.

## Overview

This project presents a scrollable narrative that examines space exploration through multiple lenses:
- International collaboration vs competition
- Economic costs vs returns
- Environmental impact vs technological benefits
- Mission outcomes and budget analysis

## Features

- **Interactive Scroll Story**: Rocket launch animation with progressive data reveals
- **12 Data Visualizations**: Each exploring different aspects of space exploration
- **Multiple Perspectives**: From budget analysis to lives saved by space technology
- **Real Data**: Uses comprehensive space exploration datasets
- **Responsive Design**: Works across desktop and mobile devices

## Project Structure

```
├── index.html          # Main HTML file
├── app.js              # Core application logic
├── styles.css          # Styling
├── assets/             # Images and visual assets
├── data/               # CSV and JSON datasets
└── js/                 # Visualization modules (one per team member)
```

## Data Sources

- Global Space Exploration Dataset
- Space economy data
- Earth disasters and climate data
- Budget and mission outcome records

## Technology Stack

- **Frontend**: Vanilla HTML/CSS/JavaScript
- **Visualization**: D3.js, Three.js
- **Data Format**: CSV, JSON

## Usage

1. Open `index.html` in a modern web browser
2. Scroll through the story to explore different visualizations
3. Each section reveals new insights about space exploration
4. Make your choice at the end: Earth First, Balance Both, or Space Forward
